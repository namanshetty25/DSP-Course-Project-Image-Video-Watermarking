Digital Watermarking for AI-Generated Media using DSP Techniques

  
EE313 · Digital Signal Processing · IIT Indore

  
This course project embeds hidden text in an image and verifies the recovered message using a secret key. It uses the Haar discrete wavelet transform and block discrete cosine transform to select image coefficients. Spread-transform dither modulation encodes the bits across those coefficients, and error correction helps recover the message after some image changes. The project also explores watermarking across video frames.
